# `inputs/`: input files for the 2PACF pipeline

Nothing in this folder except this README is tracked by git (see `.gitignore`).
Put the files below in place by hand before running:

```bash
cd codes
python run_pipeline.py parameters.yaml              # all z-bins
python run_pipeline.py parameters.yaml z7p5_9p5     # one z-bin
```

All paths are set in `codes/parameters.yaml` under `paths:` and are relative to the project folder.
`{z_bin}` in a path is replaced by each key of `survey.z_bins`, currently `z7p5_9p5` and `z9p5_14p5`.

## Layout

```
inputs/
├── README.md
├── lf_table.csv                                       # UV luminosity function vs z
├── catalogue/
│   └── candidates_450.fits                            # real galaxy catalogue
└── depth_maps/CEERS_SkyCompleteness_zbins/CEERS_SkyCompleteness_zbins/
    ├── ceers_footprint_starmask_native.fits           # survey footprint + star mask (shared by all bins)
    ├── z7p5_9p5/
    │   ├── ceers_skycompleteness_z7p5_9p5.fits        # sky completeness map, 7.5 <= z < 9.5
    │   └── ceers_skycompleteness_mocks_z7p5_9p5.fits  # injected mocks, 7.5 <= z < 9.5
    └── z9p5_14p5/
        ├── ceers_skycompleteness_z9p5_14p5.fits       # sky completeness map, 9.5 <= z < 14.5
        └── ceers_skycompleteness_mocks_z9p5_14p5.fits # injected mocks, 9.5 <= z < 14.5
```

That is **3 shared files + 2 files per redshift bin** (7 in total for two bins).

## Files

### `catalogue/candidates_450.fits` (`paths.real_catalog`)

FITS binary table of the candidate galaxies. Columns used:

| Column | Meaning |
|---|---|
| `RA`, `DEC` | sky position (deg) |
| `Z_A` | photometric redshift, used to place each galaxy in a bin's `z_a` window |
| `MUV` | absolute UV magnitude at 1500 Å, used for the `M_UV_bins` |
| `MEMBER` | `1` = final vetted sample (applied through `survey.data_cuts`) |
| `FLUX_RADIUS` | only needed when `injection.blending_check: footprint` |

Column names can be changed in `survey:` (`ra_col`, `dec_col`, `z_col`, `muv_col`).

### `depth_maps/.../ceers_footprint_starmask_native.fits` (`paths.footprint_mask`)

Image extensions `FOOTPRINT` (> 0 inside the survey) and `STARMASK` (≠ 0 where masked), on the native 0.03″
mosaic grid. Its WCS is used to place the random points, so one file is shared by all redshift bins.

### `depth_maps/.../{z_bin}/ceers_skycompleteness_{z_bin}.fits` (`paths.sky_map`)

Sky completeness map for that redshift bin (0.99″ pixels). Extensions used, for layer `n = injection.layer`
(currently 4):

- `Ln_M50`, `Ln_PMAX`, `Ln_WIDTH`: per-pixel fit of completeness vs F277W magnitude
- `FOOTPRINT_FRAC`, `UNMASKED_FRAC`: per-pixel weights for the footprint average

### `depth_maps/.../{z_bin}/ceers_skycompleteness_mocks_{z_bin}.fits` (`paths.completeness`)

FITS table with one row per injected mock galaxy. Columns used: `Z_TRUE`, `MUV_TRUE`, `MAG_IN` and the boolean
layer flag `Ln` (e.g. `L4`). The pipeline uses it to build the completeness C(M_UV, z_true).

The `CEERS_SkyCompleteness_zbins` folder comes with its own `README.md`, which describes the layers and how the
maps were made.

### `lf_table.csv` (`paths.lf_table`)

Schechter UV luminosity function parameters vs redshift, one row per `z`. Columns: `z`, `M_star`,
`log_phi_star`, `alpha`, `type` (real / interpolated / extrapolated). Generated by `codes/make_lf_table.py`.

## Optional

| Key | File | When it is needed |
|---|---|---|
| `paths.segm_map` | `survey/bundle_sextractor/detection/segmentation_total_binary.fits`: binary segmentation map on the mosaic grid | only if `injection.blending_check: footprint` (currently `none`) |
| `paths.valid_mask` | boolean image of allowed positions for the randoms | only if not `null` (currently `null`) |

## Adding a redshift bin

1. Create `depth_maps/.../<new_bin>/` containing `ceers_skycompleteness_<new_bin>.fits` and
   `ceers_skycompleteness_mocks_<new_bin>.fits`.
2. Add a `<new_bin>:` entry with `z_a`, `z_true` and `M_UV_bins` under `survey.z_bins` in `codes/parameters.yaml`.

## Not used by `run_pipeline.py`

These folders are from earlier work or notebooks. The current pipeline doesn't read them:
`CEERS_data/` (F277W mosaic sci/err/wht), `psf/`, `response_function/`, `completeness/` (`C_Mz_*.npz`), `bins/`
(`CEERS_z*_selected.csv`), and `depth_maps/CEERS_SkyCompleteness_zbins.zip` (the zipped original of the maps).
